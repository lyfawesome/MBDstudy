# 多体动力学学习路线

这份路线会随着学习反馈持续调整。当前推荐顺序是从最小物理系统出发，逐步增加几何、约束、刚体、数值稳定性和工程复杂度。

## 阶段 1：动力学求解的最小闭环

目标：理解“物理假设 -> 微分方程 -> 数值积分 -> 结果检查”。

1. 质点 Newton 方程：\(m\boldsymbol{a}=\boldsymbol{f}\)
2. 二阶微分方程转一阶状态空间
3. 显式时间积分：Euler、RK4
4. 能量、动量、误差趋势分析

## 阶段 2：坐标、自由度与运动学

目标：理解多体动力学中的“自由度”不是物体数量，而是描述系统构型所需的独立变量数量。

1. 惯性系、随体系、局部坐标
2. 广义坐标 \(\boldsymbol{q}\)、广义速度 \(\boldsymbol{u}\)
3. 旋转矩阵、角速度、欧拉角、四元数
4. 速度变换和 Jacobian

## 阶段 3：约束与 DAE

目标：理解多体系统的核心难点：约束力未知，但约束运动已知。

1. 完整约束 \(\boldsymbol{\phi}(\boldsymbol{q}, t)=\boldsymbol{0}\)
2. 速度约束与加速度约束
3. Lagrange 乘子
4. 指数缩减、Baumgarte 稳定化
5. 摆杆、滑块曲柄、四连杆

## 阶段 4：刚体动力学

目标：建立刚体平动、转动和耦合动力学的统一表达。

1. 质心平动方程
2. 刚体转动惯量
3. Euler 方程
4. 平面刚体与空间刚体
5. 质量矩阵 \(\boldsymbol{M}(\boldsymbol{q})\)、广义力 \(\boldsymbol{Q}\)

## 阶段 5：工程级求解器

目标：从单个示例过渡到可集成、可扩展的求解框架。

1. Body、Joint、Force、System 抽象
2. 稀疏矩阵装配
3. 事件、接触、摩擦
4. 数值稳定性、误差控制、步长控制
5. 与 CAD/机器人/车辆/机构仿真问题连接

## 每讲固定模板

每个知识点都按同一结构学习：

1. 物理本质：这个概念在真实世界里表达什么。
2. 数学本质：它在方程中是什么对象。
3. 工程应用：它解决什么实际问题。
4. Python 实现：把它放进求解器。
5. 验证分析：可视化、守恒量、误差趋势。
