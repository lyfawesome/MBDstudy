# 多体动力学总体学习计划

本项目采用长期、迭代式学习路线。课程不会把多体动力学拆成孤立公式，而是同时推进物理与数学、数值计算、求解器工程三条主线。

总体目标是从基本物理假设出发，最终独立建立、实现、验证和扩展一个工程级多体动力学求解器。

## 当前进度

- 已完成：第一讲质点动力学；第二讲自由度、广义坐标与无阻尼线性振子。
- 当前章节：第三讲，阻尼、外部激励、能量平衡与共振。
- 当前代码能力：固定步长 RK4、质点模型、阻尼受迫线性振子、解析解比较、能量平衡、频率响应、收敛阶和基础回归测试。
- 下一次路线调整依据：第三讲的能量平衡、稳态响应和共振理解情况。

## 三条并行主线

### 1. 物理与数学

- 明确模型假设、系统边界和适用范围；
- 定义构型、坐标、自由度、速度和受力；
- 从 Newton 定律、虚功原理或 Lagrange 方程推导控制方程；
- 理解方程中每一项的物理来源、数学类型和量纲。

### 2. 数值计算

- 把微分方程或微分代数方程转化为计算机可以求解的形式；
- 研究积分方法、误差、稳定性、收敛阶和步长选择；
- 使用解析解、守恒量、极限情况和网格收敛验证结果；
- 逐步进入非线性方程、稀疏线性系统和约束稳定化。

### 3. 求解器工程

- 每个新概念都实现为清晰、可测试、可复用的 Python 代码；
- 先让代码直接映射数学方程，再在重复需求出现后引入抽象；
- 每个案例配套理论文档、代码实现文档、趋势分析和可视化；
- 最终形成 Body、Joint、Force、Constraint、System 和 Solver 等组件。

## 每章固定学习闭环

每章围绕一个主要概念展开，基本节奏如下：

1. 提出明确的物理问题。
2. 写出建模假设、系统边界和适用条件。
3. 定义坐标、自由度、状态量、参数和单位。
4. 从基本定律推导运动方程。
5. 在运行代码前预测解的性质和参数趋势。
6. 把方程实现为可复用的 Python 模型。
7. 用解析解、守恒量、收敛阶或极限情形验证。
8. 绘制时间历程、轨迹、相图、能量和误差趋势。
9. 修改参数或模型，完成小型数值实验。
10. 根据学习反馈决定继续前进还是补充巩固。

每两到三章安排一次整合：统一符号、补充测试、整理接口，并用一个稍完整的案例连接已有知识。

## 掌握标准

完成一章不以“看完文档”为标准，而以能否完成以下任务为标准：

- 能用自己的语言解释主要概念的物理意义；
- 能独立推导核心方程，并说明每一步使用了什么假设；
- 能在仿真前判断参数变化会带来什么趋势；
- 能指出公式、数组、函数和类之间的对应关系；
- 能使用解析解、守恒量或收敛分析识别错误结果；
- 能在已有案例上完成至少一个小型代码扩展。

## 阶段 1：最小动力学求解闭环

目标：建立从物理模型到数值验证的完整闭环。

核心关系为：

$$
\text{物理模型}
\rightarrow
\text{微分方程}
\rightarrow
\text{状态空间}
\rightarrow
\text{数值积分}
\rightarrow
\text{结果验证}
$$

主要内容：

1. 质点 Newton 方程；
2. 二阶微分方程与一阶状态空间；
3. Euler、RK4 和固定步长积分；
4. 单自由度自由振动；
5. 阻尼、外部激励、能量平衡与共振；
6. 解析解比较、守恒量检查和收敛阶。

阶段成果：一个数理闭合、能够验证的常微分方程求解器。

## 阶段 2：多自由度与矩阵动力学

目标：从单个标量方程过渡到耦合的矩阵系统。

标准线性形式为：

$$
\boldsymbol{M}\ddot{\boldsymbol{q}}
+
\boldsymbol{C}\dot{\boldsymbol{q}}
+
\boldsymbol{K}\boldsymbol{q}
=
\boldsymbol{Q}(t)
$$

主要内容：

1. 多自由度状态排列；
2. 质量、阻尼和刚度矩阵；
3. 自由度之间的动力学耦合；
4. 固有频率、振型和模态坐标；
5. 线性方程组、特征值和矩阵条件数。

阶段成果：通用的二阶矩阵动力系统接口和双自由度振动案例。

## 阶段 3：坐标系与多体运动学

目标：准确描述刚体和刚体上任意点的位置、速度和加速度。

主要内容：

1. 惯性坐标系、随体坐标系和局部坐标系；
2. 构型映射与位置 Jacobian；
3. 二维旋转矩阵和角速度；
4. 三维旋转、Euler 角和四元数；
5. 刚体点的位置、速度和加速度变换；
6. 广义坐标导数与广义速度的关系。

阶段成果：坐标变换、姿态表示和刚体运动学工具。

## 阶段 4：虚功与刚体动力学

目标：建立适合多自由度和刚体系统的统一动力学表达。

主要内容：

1. 虚位移、虚功和广义力；
2. 动能、势能和功率；
3. Lagrange 方程；
4. 质心平动与刚体转动惯量；
5. Euler 转动方程；
6. 构型相关质量矩阵、科氏项和离心项。

一般动力学形式为：

$$
\boldsymbol{M}(\boldsymbol{q})\ddot{\boldsymbol{q}}
+
\boldsymbol{h}(\boldsymbol{q},\dot{\boldsymbol{q}},t)
=
\boldsymbol{Q}
$$

阶段成果：平面刚体动力学模型和可复用的质量矩阵、广义力接口。

## 阶段 5：约束与微分代数方程

目标：理解并求解由关节和几何关系产生的约束运动。

位置约束写为：

$$
\boldsymbol{\phi}(\boldsymbol{q},t)=\boldsymbol{0}
$$

主要内容：

1. 完整约束与自由度计数；
2. 位置、速度和加速度约束；
3. 约束 Jacobian；
4. Lagrange 乘子与约束反力；
5. 微分代数方程和一致初始条件；
6. 约束漂移、Baumgarte 稳定化和投影法；
7. 摆、曲柄滑块和四连杆。

阶段成果：能够组装并求解带约束的平面多体系统。

## 阶段 6：多体系统求解器架构

目标：从手写单个案例过渡到通过组件装配模型。

主要内容：

1. Body、Point、Joint、Force 和 Constraint；
2. System 负责自由度管理和方程装配；
3. Solver 负责时间推进和非线性求解；
4. 统一结果记录、诊断和可视化接口；
5. 单元测试、回归测试和基准案例；
6. 稠密与稀疏矩阵装配。

代码演进路线：

```text
通用积分器
-> 独立物理模型
-> 矩阵动力系统
-> 坐标与刚体
-> 约束与关节
-> 系统装配
-> 工程求解器
```

阶段成果：可以通过身体、关节和力组件描述机构的 Python 求解框架。

## 阶段 7：工程级问题与综合项目

目标：处理更接近真实工程仿真的数值和建模问题。

主要内容：

1. 自适应步长和误差控制；
2. 刚性方程与隐式积分；
3. 事件检测；
4. 接触、碰撞和摩擦；
5. 参数扫描、灵敏度和趋势分析；
6. 大规模稀疏系统；
7. 与 CAD、机器人、车辆或机构模型连接。

综合项目将根据兴趣选择，例如四连杆机构、机械臂、车辆悬架或空间刚体系统。

## 路线迭代规则

课程阶段保持稳定，但具体章节顺序允许调整：

- 若物理概念已经清楚而代码困难，下一章加强软件实现和数组结构；
- 若代码可以运行但推导不牢，暂停扩展并增加手算和极限情况分析；
- 若结果难以判断正误，优先补充解析基准、守恒量和收敛实验；
- 若某个概念需要后续知识才能真正理解，先记录问题，在合适阶段重新推导；
- 每章结束后根据理解反馈更新后续一到三章，而不是一次锁死全部课程。

Lesson 3 完成后先进行阶段 1 的小型整合，随后进入多自由度与矩阵动力学；若构型映射仍不清楚，则在矩阵系统之前补充 Jacobian 数值练习。
